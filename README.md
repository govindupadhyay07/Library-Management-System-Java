# 📚 Library Management System

A simple and interactive **console-based Library Management System** built using **Java ☕**.

## ✨ Features

📖 **Add New Books**
📚 **View All Books**
🔍 **Search Books by Book ID**
📤 **Issue Books**
📥 **Return Books**
✏️ **Update Book Details**
🗑️ **Delete Books with Confirmation**
🖥️ **Menu-Driven Console Interface**

## 🧠 Concepts Used

* ☕ Java
* 📦 Arrays
* 🔁 Loops
* 🔀 Conditional Statements
* 🎛️ `switch` Statements
* ⌨️ `Scanner` for User Input
* 🔍 Searching in Arrays
* ✏️ Updating Array Elements
* 🗑️ Deleting Elements by Shifting Array Elements
* 🔄 Basic CRUD Operations

## ⚙️ How It Works

The program stores book information using parallel arrays:

| Array           | Stores          |
| --------------- | --------------- |
| 🆔 `bookId[]`   | Book IDs        |
| 📖 `bookName[]` | Book Names      |
| ✍️ `author[]`   | Author Names    |
| 🔢 `quantity[]` | Book Quantities |

The user interacts with the system through a simple menu-driven interface 🎛️.

## 🚀 How to Run

1. 📥 Clone this repository.
2. 💻 Compile the Java file:

```bash
javac Librarymanagementsystem.java
```

3. ▶️ Run the program:

```bash
java Librarymanagementsystem
```
